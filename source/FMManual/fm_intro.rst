安全事项
-------------------------------------------------

为确保用户安全正确使用本产品，避免对人员造成伤害，特制定安全事项。在使用本产品前，请务必认真阅读以下安全事项：

（1）本产品的适用性请由系统设计者或规格制定者来判断。 本产品的使用条件具有多样化，请由系统的设计者或规格的制定者来判断系统的适用性。必要时请通过分析和测试进行判断。 请在参考最新的产品资料、确认规格的全部内容、考虑到可能发生的故障，在此基础上构建系统。 

（2）请具有充分知识和经验的人员使用本产品。 在此所述产品若误操作会损害其安全性。 机械装置的组装、操作、维修保养等作业请由具有充分知识和经验的人执行。 

（3）请务必在确认机械、设备的安全之后，再进行产品的使用和拆卸。

    1) 请在确认已进行了移动体的落下防止对策和失控防止对策之后再进行机械、设备的使用和维护。 
    2) 请在确认已采取上述安全措施，并切断了能量源和设备电源以保证系统安全 的同时，确认和理解设备上产品个别注意事项的基础上，进行产品的拆卸。 
    3) 重新启动机械、设备时，请对意外动作、误操作采取预防措施。 

（4）在如下所示条件和环境下使用时，请在考虑安全对策的同时，提前向我司咨询。

    1) 明确记载的规格以外的条件或环境。 
    2) 使用于原子能、铁路、航空、宇宙设备、船舶、军用、医疗设备、食品用设备、燃料装置、安全设备等场合，以及用于非产品手册中的标准规格的场合。 
    3) 预测对人身和财产有重大影响，特别是在有安全要求的场合使用时。 
    4) 用于互锁回路时，请设置应对故障的机械式保护功能，进行双重互锁。另外 进行定期检查以确认是否正常作动。

总体介绍
-------------------------------------------------

随着机器人市场规模的不断扩大，各行业对机器人关节的需求量也随之增长，促使企业开发更通用、高性能的关节产品，以满足市场的多样化需求，降低生产成本，提高市场竞争力。

安装事项
-------------------------------------------------

在安装之前，请认真阅读通用关节相关安全说明（1.1安全事项）。在固定好产品前，请勿提前打开电源。

使用条件
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

通用关节的操作及运输、存储条件为：

1. 操作环境温度: 0℃～+45℃；
2. 操作环境湿度: 20%～90% RH（40°C）（无霜无结露）；
3. 运输及储存温度: -20℃ ～ +60℃（无霜无结露）；

.. warning:: 通用关节须远离振动及冲击环境，环境不含灰尘、烟尘或水，不含腐蚀性气体、液体或爆炸性气体， 没有强大的电磁干扰源。

固件升级
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

485升级：

1. 功能树选中固件升级；
2. 选择升级方式（默认485升级）；
3. 打开要升级的固件文件（.bin）文件；
4. 发送文件开始文件传输；
5. 等待信息栏显示文件发送完成；
   
.. limage:: 031.png
   :align: center
   :width: 6in

.. centered:: 图表 7-3 固件升级图示

JLink升级：

1. 功能树选中固件升级；
2. 选择升级模式选择JLink升级（需安装JLink驱动，使用usb转JLink工具连接电脑与驱动器）；
3. 点击JLink连接，连接驱动器；
4. Flash擦除用于擦除驱动器中固件程序；
5. 打开文件选择要升级固件程序（.hex格式文件）；
6. 点击发送文件进行固件升级。

EtherCAT通信
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

EtherCAT，全称 Ethernet for Control Automation Technology，由 Beckhoff Atuomation GmbH 开发，是一种实时以太网用于主站和从站开放式的网络通信。 EtherCAT 作为成熟的工业以太网技术，具备高性能、低成本、使用简易等特点。

EtherCAT对象字典
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

PDO对象字典
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
PDO对象字典分为RxPDO和TxPDO两种。RxPDO为驱动器接收主站数据，TxPDO为驱动器向主站反馈数据。

RxPDO
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
1. 控制字（Control Word）对象字典，可读可写（RW），其索引（Index）为0x6040，子索引（SubIndex）为0，数据类型为无符号16位，下面对控制字的每个bit信息进行说明。
   
.. limage:: 042.png
   :align: center
   :width: 6in

.. centered:: 图表 8-2 控制字对象字典详细信息

其中bit3-bit0（enable operation/quick stop/enable voltage/switch on）符合Cia402协议标准，如下图所示。
   
.. limage:: 043.png
   :align: center
   :width: 6in

.. centered:: 图表 8-2 Cia402

通过控制字可将关节使能和去使能。需要使能时，应将控制字按顺序（0x06->0x07->0x0F）进行赋值；需要去使能时，应将控制字直接赋值为0。

通过控制字可进行机器人零点校准，在关节去使能和处于非OP状态时，将控制字的bit13置1。

2. 目标位置（Target Position）对象字典，可读可写（RW），其索引（Index）为0x607A，子索引（SubIndex）为0，数据类型为有符号32位。
   
.. limage:: 044.png
   :align: center
   :width: 6in

.. centered:: 图表 8-3 目标位置对象字典

通过此对象字典更新需要的目标位置，单位为pulse，上位机规划位置值，607Ah目标位置值两次的差值，需小于100000Pulse。

3. 目标扭矩（Target Torque）对象字典，可读可写（RW），其索引（Index）为0x6071，子索引（SubIndex）为0，数据类型为有符号16位。
   
.. limage:: 045.png
   :align: center
   :width: 6in

.. centered:: 图表 8-4 目标扭矩对象字典

通过此对象字典更新需要的目标扭矩，单位为额定扭矩0.1%。

4. 速度前馈（Velocity offset）对象字典，可读可写（RW），其索引（Index）为0x60B1，子索引（SubIndex）为0，数据类型为有符号32位。
   
.. limage:: 046.png
   :align: center
   :width: 6in

.. centered:: 图表 8-5 速度前馈对象字典

通过此对象字典设置合理的速度前馈。

5. 剩余的RxPDO对象字典（0x2001、0x2010、0x2011、0x2012和0x2013）未进行实际使用，不进行赘述。

TxPDO
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

1. 状态字（Status Word）对象字典，只读（RO），其索引（Index）为0x6041，子索引（SubIndex）为0，数据类型为无符号16位，下面对状态字的每个bit信息进行说明。
   
.. limage:: 047.png
   :align: center
   :width: 6in

.. centered:: 图表 8-6 状态字对象字典详细信息

首先根据bit6,5,3-0（switch on disabled/quick stop/fault/operation enabled/switched on/ready to switch on）的组合可以确定功率状态机的状态，下图为具体说明。
   
.. limage:: 048.png
   :align: center
   :width: 6in

.. centered:: 图表 8-7 功率状态机状态确认表

- bit13（home）：1的情况下表示已校零。
- bit12（drag）：1的情况下表示进入拖动模式。
- bit5（quick stop）：0的情况下表示功率状态机接收quick stop要求。
- bit4（voltage enabled）：1的情况下表示主电路电源电压加到主回路。

2. 当前位置（Position Actual Value）对象字典，只读（RO），其索引（Index）为0x6064，子索引（SubIndex）为0，数据类型为有符号32位。
   
.. limage:: 049.png
   :align: center
   :width: 6in

.. centered:: 图表 8-8 当前位置对象字典

通过此对象字典获取关节当前的位置数据，单位为pulse。

3. 故障码（Error Code）对象字典，只读（RO），其索引（Index）为0x603F，子索引（SubIndex）为0，数据类型为无符号16位。
   
.. limage:: 050.png
   :align: center
   :width: 6in

.. centered:: 图表 8-9 故障码对象字典

4. 实时扭矩（Torque Actual Value）对象字典，只读（RO），其索引（Index）为0x6077，子索引（SubIndex）为0，数据类型为有符号16位。
   
.. limage:: 051.png
   :align: center
   :width: 6in

.. centered:: 图表 8-10 实时扭矩对象字典

通过此对象字典获取关节的实时扭矩数据，单位为额定扭矩0.1%。

5. 实时速度（Velocity Actual Value）对象字典，只读（RO），其索引（Index）为0x606C，子索引（SubIndex）为0，数据类型为有符号32位。
   
.. limage:: 052.png
   :align: center
   :width: 6in

.. centered:: 图表 8-11 实时速度对象字典

通过此对象字典获取关节的实时速度数据，单位为rmp。

6. 剩余TxPDO对象字典（0x2000、0x3010、0x3011、0x3012和0x3013）未实际使用，不进行赘述。

1. 软件版本（Sofeware version）对象字典，只读（RO），其索引（Index）为0x100A，子索引（SubIndex）为0，数据类型为可见字符串。

2. 基本设定（sBaseSetPara）、通信参数（sCommPara）对象字典、驱动参数（sDrivePara）对象字典、监控参数（sDisplyPara）对象字典、调整参数（sAdjPara）对象字典、运动控制（sMtCtrlPara）对象字典、保护参数（sKeepPara）对象字典、辅助功能（sAuxPara）对象字典、限制参数（sLmtPara）对象字典、输入输出1（sIoPara1）对象字典、输入输出2（sIoPara2）对象字典、自适应PID刚度0~2对象字典、闭环前馈控制对象字典、闭环PID模式对象字典。详见附录2：Sdo读写驱动器全参数表-V0.4-20251208
